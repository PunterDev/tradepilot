# Access Review Procedure

## Purpose

Define the quarterly process for reviewing production and privileged access.

## Scope

Systems reviewed: GitHub, Vercel, Render, Supabase, Stripe, OpenAI, Qdrant, Databento, Resend, domain/DNS provider, and TradePilot ADMIN accounts.

## Procedure

1. Schedule the quarterly access review and assign a reviewer.
2. Export or screenshot each system's users, roles, MFA status, and access level.
3. Record each user in `docs/compliance/evidence/templates/ACCESS_REVIEW_TEMPLATE.md`.
4. Confirm business need with the relevant Service Owner.
5. Mark each access grant as keep, remove, or change.
6. Complete removals or role changes promptly.
7. Record action completion date and reviewer notes.
8. Update `docs/compliance/registers/PRODUCTION_ACCESS_REGISTER.md`.
9. Retain evidence without secrets, tokens, passwords, or API keys.

## Evidence

Completed access review template, redacted access exports, MFA evidence, action-completion records, and management signoff.
